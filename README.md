# Python Project: A Simple Calculator

In this project, I created a simple calculator with which the user can do four types of calculation (addition, subtraction, multiplication, and division) with two numbers.

First, the calculator prompts the user to input their type of calculation and numbers of choice, and then it returns the result of the calculation.

After the calculation is done, it asks the user if they want to do another calculation. If they say yes, another round of calculation starts. If no, the calculator shuts down.
